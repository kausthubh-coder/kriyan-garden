3. Add goal

The same shape as quick add: a plain title line, then three rows of chips. No dropdowns, no raw date boxes, no "Close dialog" text button (Escape and a click outside close it). "Pick a day" reveals a date field. Choosing "A number" reveals target and unit fields. Start date is today and is changed later in the goal panel. Validation is a sentence under the title; the browser's own validation bubble is turned off.
