Editors per row. Area: area chips. Project: chips for the area's projects plus "None". Day: Today, Tomorrow, the next two weekdays by name, No date, and "Pick a day" which reveals a date input. "At start" and "before" chips are disabled with the line "Set a time to use these" when the task has no time.
