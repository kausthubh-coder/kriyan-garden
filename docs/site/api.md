# API

The planned versioned API lives at `https://app.kriyan.app/api/v1`. It shares the Convex operations layer with the web app, MCP and CLI. Requests are authenticated with Clerk; rows belong to the verified identity.

This is an integration placeholder for brief 05. No docs/api.md existed in this checkout. Endpoint paths, request and response schemas, scopes, rate limits and examples are pending that worker's finalized documentation. Do not build an integration from guessed endpoints.

Use the [web app](https://app.kriyan.app/app) or [public demo](/demo) while you review the [implementation plan](https://github.com/kausthubh-coder/kriyan-garden/blob/main/docs/PLAN.md). Keep API keys in your own secret store and never include them in issue reports.
