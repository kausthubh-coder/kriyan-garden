# Security

Report a suspected vulnerability privately to [kausthubh2007@gmail.com](mailto:kausthubh2007@gmail.com). Include the affected revision, reproduction steps, impact and a minimal example using your own test account. Do not send credentials, environment files or another person's planner data.

Please avoid publishing details before the maintainer can investigate and arrange a fix. Do not access or modify other users' data, disrupt availability or run broad scans against the hosted service. Use a local or independently hosted test deployment.

Kriyan does not offer a paid bug bounty. The current main branch is the supported development version; released versions and support windows will be documented when releases are available. Reports will be reviewed as maintainer availability permits, without a guaranteed response deadline.
